# GeoChanger

Простое Android-приложение для подмены геопозиции: выбираешь точку на карте (или через поиск города) — телефон начинает сообщать её как своё местоположение всем приложениям.

[Политика конфиденциальности](https://z3z4.github.io/GeoChanger/)

## Что внутри

- **Kotlin + Jetpack Compose** — интерфейс
- **osmdroid** (карта OpenStreetMap) — бесплатно, без API-ключей
- **Nominatim** — поиск городов и адресов (API OpenStreetMap)
- **Foreground-сервис** — подмена работает, даже когда приложение свёрнуто; в шторке висит уведомление с кнопкой «Остановить»

## Сборка APK

Командная строка (JDK 17+ и Android SDK):

```
gradlew.bat assembleDebug
```

Готовый APK: `app\build\outputs\apk\debug\app-debug.apk`

Release-версия для Google Play (Android App Bundle):

```
gradlew.bat bundleRelease
```

Готовый AAB: `app\build\outputs\bundle\release\app-release.aab`

Подпись релиза берётся из `keystore.properties` + `keystore/geochanger-release.jks` (в git не попадают, у каждого свой ключ). Без этих файлов release соберётся неподписанным.

В `local.properties` путь к SDK: `F:\AndroidStudioSDK`, JDK — `F:\AndroidStudioo\jbr`. Проект также можно просто открыть в Android Studio (папка `F:\AndroidStudioo`).

## Первая настройка на телефоне (один раз)

1. **Настройки → О телефоне** → нажать 7 раз на «Номер сборки» — станут доступны «Для разработчиков».
2. **Настройки → Для разработчиков → Приложение для фиктивных местоположений** (на некоторых прошивках: «Выбрать приложение для фиктивных местоположений») → выбрать **GeoChanger**.
3. При первом нажатии «Установить позицию» разрешить доступ к местоположению (требование Android 14+) и уведомления.

## Использование

- Двигай карту — точка под перекрестием в центре экрана и есть будущая позиция, координаты показаны под картой.
- Поиск: начни вводить название города — появится список, тап переносит карту.
- **«Установить позицию»** — включает подмену (кнопка краснеет и меняется на «Остановить»).
- **«Остановить»** (в приложении или в уведомлении) — возвращает реальную геопозицию.
- Позиция карты запоминается между запусками.

## Ограничения

- Работает только через официальный механизм Android «фиктивные местоположения» — root не нужен, но приложение должно быть выбрано в настройках разработчика.
- Приложения, которые проверяют флаг «mock location» (банки, Pokémon GO и т.п.), распознают подмену — это ограничение самого механизма, без root оно не обходится.
- После перезагрузки телефона подмена сбрасывается — нужно нажать кнопку заново.

## Структура проекта

```
app/src/main/java/com/geochanger/app/
├── MainActivity.kt          — экран: карта, поиск, кнопка старт/стоп
├── MockLocationService.kt   — foreground-сервис, раз в секунду пишет координаты в GPS/NETWORK провайдеры
├── MockLocationHelper.kt    — проверка, выбрано ли приложение как «фиктивные местоположения»
├── MockState.kt             — состояние «подмена активна» для UI
└── NominatimClient.kt       — поиск по базе OpenStreetMap
```
